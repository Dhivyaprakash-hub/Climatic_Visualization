# Climate Data Coursework

This group coursework explores annual and monthly mean temperature data for 20 countries. `Countries.csv` contains the data table and the PDF contains the original project report.

The repository currently provides source data and the report; it does not include a reproducible charting application or a documented data source. Treat the figures as coursework data, not current climate measurements. A future version should document its source, units, reference period, and chart-generation steps.
